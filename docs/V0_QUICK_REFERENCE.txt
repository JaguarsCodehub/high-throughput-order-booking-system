┌─ WHAT'S IN V0 (Intentionally Broken) ──────────────────────────────────────────┐
│  ✗ No resource limits       → Pods consume unlimited memory → OOMKilled
│  ✗ No liveness probes       → Dead pods don't restart
│  ✗ No readiness probes      → Traffic routes to unready pods
│  ✗ No startup probes        → Services don't wait for dependencies
│  ✗ No PersistentVolumes     → Data lost on pod restart
│  ✗ No Ingress              → Exposed via NodePort (ugly, insecure)
│  ✗ :latest image tags      → Non-reproducible, slow
│  ✗ Single replicas         → No redundancy
│  ✗ Running as root         → Security risk
│  ✗ Plaintext secrets       → Password in git
│  ✗ No CI/CD                → Manual deployments
│  ✗ No graceful shutdown    → In-flight requests drop
│  ✗ No observability        → Blind to what's happening
│  
│  Each of these will be FIXED in V1!
└────────────────────────────────────────────────────────────────────────────────┘
