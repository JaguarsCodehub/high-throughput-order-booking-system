BONUS: GitHub Actions vs Circle CI

GitHub Actions:
  ✅ Free for public repos
  ✅ Native GitHub integration
  ✅ Simpler YAML syntax
  ✅ Good ecosystem
  ❌ Slower builds sometimes

Circle CI:
  ✅ Faster builds (parallel jobs)
  ✅ Better free tier (2.5k credits/month)
  ✅ Mature platform
  ❌ Overkill for this project
  ❌ More complex setup

PICK: GitHub Actions (sufficient, simpler, free)
